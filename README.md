# Progra-I

Este repositorio contiene una colección de programas desarrollados como parte del curso de Programación I. Los programas están organizados en diferentes carpetas según su tipo y propósito, y abarcan conceptos fundamentales de programación en C.

## Estructura del Proyecto

- **docs/**: Documentación adicional.
- **bin/**: Archivos ejecutables generados.
- **src/**: Archivos fuente del proyecto.
- **Actividad integradora/**: Contiene programas relacionados con actividades integradoras del curso.
- **Lista 5/**: Ejercicios de la lista 5.
- **Moly/**: Prácticas adicionales.
- **Programas iterativos/**: Programas que implementan estructuras de control iterativas.
- **Programas secuenciales/**: Programas que siguen una estructura secuencial básica.
- **Programas seleccion múltiple/**: Programas que utilizan estructuras de selección múltiple como `switch`.
- **Programas selectivos/**: Programas que implementan estructuras de selección simple o compuesta.

## Requisitos

- **Compilador**: Se recomienda utilizar `gcc` para compilar los programas.
- **Entorno**: Un entorno de desarrollo compatible con C, como Visual Studio Code o cualquier editor de texto con soporte para C.

## Compilación y Ejecución

Para compilar un archivo, utiliza el siguiente comando en la terminal:

```bash
gcc <nombre_del_archivo>.c -o <nombre_del_archivo>.exe
```

Para ejecutar el programa compilado:

```bash
./<nombre_del_archivo>.exe
```

## Cambios en la Organización del Proyecto

Se han realizado los siguientes cambios para mejorar la organización del proyecto:

1. **Estandarización de nombres**:
   - Se recomienda usar nombres consistentes y en inglés para carpetas y archivos.

2. **Nueva estructura de carpetas**:
   - `docs/`: Documentación adicional.
   - `bin/`: Archivos ejecutables generados.
   - `src/`: Archivos fuente del proyecto.

3. **Movimientos de archivos**:
   - Archivos como `idkman.c` se han movido a `src/` para mantener una estructura más limpia.
